# 衣架购物页生成器 · Hanger Shopping Page

将服装正面照片制作成自然侧挂、正面悬挂素材与衣架购物交互单页。

## 手机交互

- 首页展示三件侧挂服装。
- 拖动实际衣服，在原架拨正并居中，两侧露出相邻侧挂款。
- 底部横向浏览轴用于查看整排服装，不与衣服拖拽混淆。
- 轻点打开单品详情，支持切款、正面/侧挂切换。
- 详情空白处或 CLOSE 可关闭，箭头与其他操作按钮不会误关闭。

使用透明图片和 WebGL 网格实现悬挂与惯性效果，提供非 WebGL 图片回退。页面不包含支付、库存和订单后台。

## 安装后如何使用

### 1. 提供服装正面照片

在支持 Skill 的 AI 编程工具里新建一个任务，上传一款或多款清晰的服装正面照。每款一张即可；已有透明底图片也可以直接使用。提供多款时，说明每张图片对应哪一款。

### 2. 复制这句话开始

```text
用 $hanger-shopping-page，把我上传的服装正面照片做成衣架购物交互单页。
这次用于个人学习。品牌名、slogan和配色用默认，不展示价格。
请先生成同款的自然侧挂图和正面悬挂图，再生成可离线打开的HTML页面。
```

不需要先自己制作侧挂图，也不需要逐步描述代码。AI 会检查照片，生成两种悬挂视角，再制作页面。

### 3. 有展示偏好时一起说明

可以在上面的指令后补充：

```text
练习页面名称：My Hanger
slogan：慢慢挑选喜欢的那一件
配色：暖米色、鼠尾草绿
展示品名，不展示价格或购买入口。
我主要在手机上体验，请提供手机样机预览；
拖衣服拨正，底部横向浏览轴查看所有款式，轻点进入详情，点详情空白处关闭。
```

如果不确定，回复“默认”即可。希望显示价格时请提供每款价格；未提供的价格不会自动编造。

### 4. 打开交付文件并核对

完成后会交付：

- **HTML交互页面**：在浏览器中打开体验。
- **每款侧挂图与正面悬挂图**：核对衣长、领口、花纹及衣架遮挡。
- **可编辑源码和配置**：用于后续调整；已确认版本应另存保留。
- **手机样机预览**：在指令中提出需要后交付。

发现款式或交互不对，直接指出具体哪件、哪个动作，让AI定向修改。素材生成和浏览器检查能力取决于所用工具；没有生图能力时，需先提供已制作好的悬挂图片。

如果工具没有识别 `$hanger-shopping-page`，请确认安装目录内保留了 `SKILL.md`，让工具读取已安装的该文件后按说明执行。下载 Skill ZIP用于制作新页面；小红书工具ZIP是当前演示的上传包，二者用途不同。

- [Skill ZIP](downloads/hanger-shopping-page-v1.zip)：用于支持 Skill 的 AI 编程环境。
